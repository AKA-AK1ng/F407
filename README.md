# F407 RNG 测试工程

基于 STM32F407，通过 USART1 接收命令，测试片上硬件 RNG 及随机多项式生成。

---

## 硬件接线

| 信号 | STM32F407 引脚 | USB-TTL 模块 |
|------|---------------|-------------|
| TX   | PA9 (USART1_TX) | RX |
| RX   | PA10 (USART1_RX) | TX |
| GND  | GND | GND |

> **注意**：TX↔RX 需交叉连接；必须共地。LED 指示灯接 PF9 (LED1)、PF10 (LED2)，低电平点亮。

---

## 串口参数

| 参数 | 值 |
|------|----|
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控   | None |

---

## 支持的命令（单字符，大小写均可）

| 命令 | 功能 |
|------|------|
| `R` / `r` | 调用 `random_bytes(buf, 16)`，打印 16 字节随机数（十六进制） |
| `P` / `p` | 调用 `random_poly_uniform(&p)`，打印多项式前 10 个系数 |
| `E` / `e` | 调用 `random_poly_eta(&p)`（CBD 采样），打印多项式前 10 个系数 |
| 其他字符   | 打印 `INVALID CMD` |

串口助手直接发送单个字母（如 `R`），无需换行符。

---

## 接收工作原理

1. 上电后，`HAL_UART_Receive_IT(&huart1, (uint8_t *)&rx_buffer, 1)` 启动 1 字节中断接收。
2. 每收到 1 字节，进入 `HAL_UART_RxCpltCallback`：
   - **LED1（PF9）翻转**，每收到 1 字节闪烁一次，硬件可见。
   - 将字节写入 `volatile char cmd`，置位 `volatile uint8_t cmd_flag`。
   - 重新调用 `HAL_UART_Receive_IT` 以持续接收。
3. 主循环检测 `cmd_flag`，打印 `RX: 0xXX ('X')` 调试信息，再根据命令执行对应操作。

> **关键实现细节**：`rx_buffer`、`cmd_flag`、`cmd` 均声明为 `volatile`，防止编译器优化将其缓存在寄存器中导致主循环读不到中断中的修改。

---

## 排查步骤（若发送后无反应）

1. **检查回显**：串口助手发送 `R`，若立即看到 `R` 被回显 → 接收链路正常，问题在主循环或命令判断。
2. **检查 LED1**：每收到字节 LED1 应翻转；若 LED 无变化 → 中断未触发，检查接线或串口参数。
3. **检查 RX 调试行**：主循环正常处理时会先打印 `RX: 0x52 ('R')`，若未出现 → `volatile` 缺失或中断优先级问题。
4. **确认串口参数**：波特率、数据位、停止位、校验位必须与上表完全一致。
5. **确认接线**：TX↔RX 交叉、已共地、接的是 PA9/PA10（USART1），不是 PA2/PA3（USART2）。
6. **确认命令字符**：直接发单个大写或小写字母（`R`/`P`/`E`），不含换行符（如果串口助手默认附加 `\r\n`，会先收到命令字符再收到 `\r`，`\r` 会触发 `INVALID CMD`，属正常现象）。
